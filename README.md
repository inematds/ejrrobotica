# EJR Robótica — proposta de novo site

Redesenho de https://ejrrobotica.com.br/ — site estático (HTML + CSS + JS, sem build).

**Ver online:** https://inematds.github.io/ejrrobotica/

O destaque é a arena no topo: o visitante programa um robô com os comandos
PF, PT, PE e PD (os mesmos dos jogos da EJR) e leva ele até três alvos.

- Plano completo, identidade e pendências de conteúdo: [PLANO.md](PLANO.md)
- Rodar localmente: abra `index.html` no navegador.
